# LanguageFriction

一个基于 Expo SDK 56 和 TypeScript 的空白应用。

## 开始使用

```sh
npm install
npm start
```

在 Expo 开发服务器中选择 Android、iOS 或 Web，也可以分别运行 `npm run android`、`npm run ios` 或 `npm run web`。应用入口为 `App.tsx`。

运行 `npm run typecheck` 检查 TypeScript 类型。领域模型的初始设计见 [docs/initial-domain-model.md](docs/initial-domain-model.md)。
